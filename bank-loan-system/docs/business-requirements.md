# Business Requirements

## Problem

Ручная обработка кредитных заявок увеличивает время принятия решения и вероятность операционных ошибок.

## Business Goal

Автоматизировать стандартный процесс обработки кредитной заявки и сократить время получения предварительного решения.

## Success Metrics

| KPI | Target |
|---|---:|
| Время обработки стандартной заявки | < 5 сек |
| Доля автоматически обработанных заявок | > 80% |
| Потеря истории статусов | 0 |
| API response time | < 500 мс |

## Out of Scope

- реальное заключение договора;
- интеграция с БКИ;
- полноценный KYC/AML;
- production ML-модель;
- полноценная IAM-система.
